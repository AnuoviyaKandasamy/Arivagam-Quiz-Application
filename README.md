# Arivagam-Quiz-Application
Arivagam is a console-based quiz application built using Core Java, OOP, Collections Framework, Stream API, and File I/O, featuring multiple categories, difficulty levels, real-time scoring, and leaderboard management.

Arivagam is a feature-rich console-based quiz application developed using Core Java to provide an interactive learning and assessment experience. The application allows users to participate in quizzes across multiple categories and difficulty levels while tracking their performance through a real-time scoring system and persistent leaderboard.

The project demonstrates the practical implementation of Object-Oriented Programming (OOP), Java Collections Framework, Stream API, Generics, and File I/O concepts to build a scalable and maintainable console application.
